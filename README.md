# cos-py

研究背景および目的

近年、アニメやゲームなどのコンテンツ産業の拡大に伴い、SNSや専門プラットフォームに投稿されるコスプレ画像が急増しています。しかし、これ
らの画像に対するキャラクター名のタグ付けは手動で行われており、表記揺れや未設定が多いため検索性が低いという課題があります。本研究は、コス
プレ画像から登場キャラクターを自動で高精度に推定・タグ付けするシステムの実現を目的としています。
本研究における最大の技術的課題は、「2次元（アニメイラスト）」と「3次元（実写コスプレ写真）」の間に存在する広大な「ドメインギャップ」の
克服です。イラスト特有のデフォルメされた表現に対し、実写画像は撮影環境の照明、衣装の質感、レタッチソフトによる加工フィルタなどの複雑なノ
イズ成分を含んでいます。そのため、従来のイラスト対象モデルや一般的な人物顔認識モデルをそのまま適用しても高精度な識別は困難です。そこで本
研究では、このドメイン間の乖離を埋め、実世界の実写ノイズに左右されないロバストなキャラクター推定手法の確立を目指しています。
